## 🔖 Project Title
**Student Management API – FastAPI (CRUD Application)**

---

## 📝 Project Description
A simple **CRUD (Create, Read, Update, Delete)** REST API built with **FastAPI** to manage student records.
This project demonstrates how to create endpoints for adding, updating, deleting, and retrieving students using **FastAPI** and **Pydantic**.

---

### ✨ Features
* Add new students
* View all students
* Get a student by roll number
* Update student details
* Delete student records

---

### 🛠️ Tech Stack
* Python 3
* FastAPI
* Pydantic
* Uvicorn
